◆ diagnostics_periodic()

void diagnostics_periodic ( void )

Samples task statistics and estimates CPU utilization.

Records task IDs, names, states, and stack high-water marks. Calculates each task's CPU utilization from the runtime difference between samples. Overall CPU utilization is calculated as 100% minus the idle task's utilization.

Note
CPU utilization requires a previous sample and a valid runtime delta.
This function should only be called by one task at a time.
