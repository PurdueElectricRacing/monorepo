◆ ADBMS_init()

void ADBMS_init ( adbms_bms_t * bms,
SPI_InitConfig_t * spi )

Initialize the ADBMS driver instance and underlying ADBMS6380 device chain.

Sets the driver state to CONNECTING, clears discharge and error flags, deasserts CS, and configures the internal SPI TX/RX buffers.

Parameters
bmsNon-null pointer to driver state to initialize.
spiNon-null SPI configuration used for ADBMS transactions.
