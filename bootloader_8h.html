bool BL_checkAndBoot ( void )

Validate the committed image and transfer control to it.

Metadata, vector-table values, and application CRC are checked before VTOR and MSP are changed.

Returns
false when validation fails or the application reset handler returns.

◆ BL_poll()

void BL_poll ( void )

Process every frame currently queued by the FDCAN receive interrupt.

Call repeatedly from main context. This function is the sole queue consumer and owns all flash and CRC work; the receive ISR only copies matching frames into the bounded software queue.
