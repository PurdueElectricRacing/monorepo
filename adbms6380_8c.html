◆ ADBMS6380_read_cell_voltages()

void ADBMS6380_read_cell_voltages ( adbms6380_t * dev)

Read all cell voltages from each chip via RDCVA..RDCVF.

Converts raw values to volts and populates each chip's cell_voltages array. If any command fails with a PEC error after retries, the successfully read cell voltages are still updated and the corresponding flag in err_cell_voltage_pecs is set.
