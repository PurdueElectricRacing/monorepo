Detailed Description

Geodetic coordinate utility header.

Projects GPS latitude/longitude onto a local cartesian plane so that planar geometry can be used on it.

◆ geodetic_to_local()

static vector2_t geodetic_to_local ( const geodetic_coord_t origin,
const geodetic_coord_t coord )
inlinestatic

Project a coordinate onto a local east-north plane about an origin.

Equirectangular approximation: northing is proportional to latitude, and easting is compressed by the cosine of the origin latitude. Sub-meter accurate over the few kilometers a track spans, and linear, so straight lines stay straight and segment geometry remains valid.

Parameters
originThe coordinate that maps to (0, 0)
coordThe coordinate to project
Returns
East (x) and north (y) offset from the origin, in meters.
