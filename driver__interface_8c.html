◆ PHAL_EXTI_callback()

void PHAL_EXTI_callback ( GPIO_TypeDef * bank,
uint8_t pin )

Weak callback invoked for each pending GPIO EXTI line.

Called from an EXTI interrupt handler. Keep overrides short and non-blocking. For both-edge triggers, sample the GPIO input to determine its current level. The default implementation does nothing.

Parameters
bankGPIO port that generated the interrupt
pinPin number, 0-15
