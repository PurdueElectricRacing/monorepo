Detailed Description

All board-specific details needed by the bootloader transport.

IDs are kept as raw CAN IDs; is_extended_id determines whether they are placed in the standard or extended field of a FDCAN frame. GPIO entries are values rather than pointers so every entry can be initialized in the same table without transport-specific code in bootloader.c.
