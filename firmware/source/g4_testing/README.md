## G4 Testing
The G4 testing node is used for rapid iteration and generic bench testing. It should not be deployed onto the vehicle.
See [clock_testing.md](clock_testing.md) for a beginner-friendly guide to
flashing a G4 board and bench-testing the 170 MHz clock (RCC self-test, SPI
loopback, and two-board SPI/UART tests between a 16 MHz and a 170 MHz board).
